📝 AI Text Summarizer

An interactive **AI-based Text Summarizer** built using **Python** and **Streamlit**.  
It summarizes long text into concise, meaningful summaries using **TF-IDF** and **Natural Language Processing (NLP)** techniques.

---

🚀 Features
- 🧠 AI-powered text summarization
- 🔢 Select summary length (1–10 sentences)
- ⚡ Instant summary generation
- 🧹 Clear input & output with one click
- 💾 Session-state based (no accidental resets)
- 📱 Responsive layout

---

🛠️ Tech Stack
- Python 3.14
- Streamlit
- NLTK
- Scikit-learn
- NumPy

⚙️ Installation & Setup

1️⃣ Clone the Repository
git clone https://github.com/your-username/text-summarizer.git  
cd text-summarizer

2️⃣ Create Virtual Environment (Optional)
python -m venv venv  
venv\Scripts\activate

3️⃣ Install Dependencies
pip install -r requirements.txt

▶️ Run the App
streamlit run app.py
        OR
python -m streamlit run app.py

---

📌 How It Works
1. Paste text into the input box
2. Choose summary length (1–10 sentences)
3. Click Generate
4. View summarized output
5. Use Clear to reset
